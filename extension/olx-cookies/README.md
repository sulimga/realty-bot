# Автобот — вхід для бота (Chrome, режим розробника)

1. Chrome → `chrome://extensions` → увімкнути «Режим розробника» (праворуч вгорі).
2. «Завантажити розпаковане» → вибрати цю папку (`extension/olx-cookies`).
3. Відкрити olx.ua (залогіненим) → іконка розширення → «Скопіювати вхід OLX для бота».
4. У боті: «🍪 Cookies» → OLX → «Тимчасовий токен / cookie» → вставити.

Токен живе ~15 хв: якщо в попапі написано, що протух — «Оновити сторінку і зловити свіжий токен».
Розширення нічого нікуди не відправляє — лише кладе текст у буфер обміну.
