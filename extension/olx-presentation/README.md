# Автобот — презентація з OLX (Chrome, режим розробника)

З оголошення OLX робить презентацію для клієнта в стилі публічних презентацій CRM:
тип угоди / тип об'єкта, ціна (і за м², для землі за сотку), адреса, площа, кімнати, поверх,
призначення (житлова / нежитлова), усі параметри OLX, опис і фото. Далі — **PDF** або сторінка **Telegraph**.

## Встановлення
1. Chrome → `chrome://extensions` → увімкнути «Режим розробника».
2. «Завантажити розпаковане» → вибрати цю папку (`extension/olx-presentation`).
3. Закріпити іконку (пазл на панелі → шпилька).

Оновлення: замінити файли в папці → на `chrome://extensions` натиснути ↻ на картці розширення.

## Як користуватись
1. Відкрити оголошення на olx.ua → натиснути іконку розширення.
2. Відкриється нова вкладка з презентацією. Усе можна правити прямо на сторінці:
   - заголовок, ціну, будь-яку графу таблиці (клік по тексту); ✕ — прибрати рядок, «+ додати рядок» — свій (напр., житлова площа);
   - опис (галочка «Без контактів продавця» прибирає телефони, посилання, email, @нікнейми — увімкнена одразу);
   - фото: ★ — зробити головним, ✕ — прибрати;
   - «Ціна» — показувати / ховати ціну; «Мої контакти» + ⚙ — ваше ім'я й телефон унизу.
   Правки зберігаються самі (розширення пам'ятає 30 останніх презентацій).
3. **🖨 PDF** → у вікні друку вибрати «Зберегти як PDF». Назва файлу — заголовок презентації.
4. **✈ Telegraph** → сторінка на telegra.ph, посилання копіюється в буфер. Повторне натискання **оновлює ту саму сторінку**
   (посилання не міняється). Акаунт Telegraph створюється сам при першій публікації, токен лежить лише в цьому браузері.

Посилання на OLX, ID оголошення і дані продавця в презентацію не потрапляють.

⚠️ Фото в Telegraph — прямі посилання на сервер фото OLX (завантаження файлів у Telegraph вимкнене).
Якщо оголошення на OLX видалять, фото на сторінці Telegraph можуть зникнути. PDF — назавжди.

## Якщо щось не зчиталось
OLX час від часу міняє сторінку. Якщо порожньо (немає фото, опису, параметрів) — натисніть **🐞**,
збережеться файл `olx-<ID>-dani.json` (лише дані оголошення, без продавця). Надішліть його Claude — підлаштуємо.

## Як влаштовано (для розробки)
```
manifest.json          MV3; дозволи: activeTab, scripting, storage; сайти: *.olx.ua, api.telegra.ph
sw.js                  клік по іконці → sources/<сайт>.js → chrome.storage.local → presentation.html#pres_<час>
sources/olx.js         зчитування: стан сторінки (__PRERENDERED_STATE__) → API /api/v1/offers/<id>/ → DOM і JSON-LD
sources/index.js       список сайтів-джерел (сюди ж додавати dom.ria / rieltor.ua)
lib/normalize.js       сирі дані → модель презентації (тип, призначення, адреса, площі, ціна за м², опис, фото)
lib/categories.js      дерево категорій OLX «Нерухомість» (згенероване з boards/olx/categories.json)
lib/telegraph.js       модель → вузли Telegraph, createAccount / createPage / editPage
presentation.*         сторінка презентації, редагування, друк (A4) і Telegraph
test/normalize.test.js тести на штучних даних: `node test/normalize.test.js`
```

### Оновити категорії
Після оновлення `boards/olx/categories.json` (з кореня репозиторію):
```
python3 - <<'EOF'
import json
c = json.load(open('boards/olx/categories.json'))
rows = [f'  {k}: [{json.dumps(v["label"], ensure_ascii=False)}, {v["parent"]}],' for k, v in sorted(c.items(), key=lambda x: int(x[0]))]
open('extension/olx-presentation/lib/categories.js', 'w').write(
  "// Дерево категорій OLX «Нерухомість»: id → [назва, батько].\n"
  "// Згенеровано з boards/olx/categories.json (див. README, розділ «Оновити категорії»).\n"
  "export const OLX_CATS = {\n" + "\n".join(rows) + "\n};\n")
EOF
```
